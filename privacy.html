PRIVACY NOTICE

Privacy before contractor matching.

Last updated: September 13, 2026

Current browser-based tools

The current RepairCostMatch planning tools run primarily in your browser. They may ask about the visible home problem, perceived severity, foundation type, ZIP code and an optional symptom description. Those details are used to organize an educational planning result on screen. RepairCostMatch does not currently submit that repair profile to a contractor, marketplace or referral partner.

Photos

If you choose a repair photo, the current version creates a temporary local preview for the active browser session. RepairCostMatch does not upload or analyze that photo with an AI service in the current version. Closing or refreshing the session may remove the temporary preview.

Voice description

Voice input, when supported, uses the speech-recognition capability provided by your browser. Availability and processing vary by browser and device, and the browser provider may process audio under its own terms. RepairCostMatch itself does not receive or store the voice audio in the current implementation. Review the transcribed text before continuing.

Project Hub and local storage

If you tap “Save project,” a limited repair snapshot is stored in your browser's local storage on that device. It can include the selected problem, severity, foundation type, ZIP code, planning result and symptom text. It is not synced to a RepairCostMatch account or cloud database in the current version. You can remove individual saved projects in Project Hub or clear the site's browser storage.

Quote checker and comparison

If you use “Is this quote fair?” and save a quote for comparison, the current version stores the contractor or quote label you enter, quoted amount, selected repair profile, warranty length, checklist status and optional ZIP shown from the repair check in local browser storage. Saved quote comparisons are not uploaded to RepairCostMatch or sent to contractors in the current version. You can delete saved quotes from the comparison area or clear the site's browser storage.

No contact information required to start

The current planning flow does not require your name, email address or phone number. Do not enter Social Security numbers, payment-card information, account credentials, medical information or other sensitive identifiers into symptom descriptions, saved projects or quote labels.

Offline and installable web app files

RepairCostMatch may use a service worker and browser cache so public site files can load more reliably or support an installable web-app experience. This cache is for public website assets and is not intended to upload repair-profile data.

Future partner referrals

If RepairCostMatch later connects to a contractor-matching or home-services partner, the product will explain what information is being shared and ask for appropriate consent before sending a repair profile or contact information. Any separate marketing, call or SMS consent must be presented clearly rather than hidden in the basic planning flow.

Analytics

Analytics may be added to measure page visits and product interactions. Repair-profile details such as ZIP code, specific home symptoms, saved quote amounts and contact information should not be sent as analytics event parameters. This notice will be updated before any analytics or advertising technology materially changes how data is handled.

Security

Private partner credentials, API keys and lead-routing secrets must remain on secure server-side systems and must not be placed in public website code. If persistent personal information is collected later, RepairCostMatch intends to use access controls, retention limits and a deletion process appropriate to the integration.

Changes

This notice will change as the service adds contractor matching, analytics, payments or other features. Material changes should be published before the relevant feature is used for live customer data.
