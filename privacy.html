PRIVACY NOTICE

Privacy before contractor matching.

Last updated: September 16, 2026

Browser-based planning tools

RepairCostMatch planning tools primarily run in your browser. They may use the visible problem, perceived severity, foundation type, ZIP code and optional symptom description to organize an educational planning result. RepairCostMatch does not automatically send your repair profile to a contractor or referral partner.

Pro AI Repair Assistant

If you choose to use the Pro AI Repair Assistant, the question you type and a limited current repair profile — such as problem category, severity, foundation type, ZIP code, screening score, DIY suitability and planning result — are sent securely to an AI service to generate the answer. Do not enter passwords, payment-card information, Social Security numbers, medical information or other sensitive personal information in AI questions.

RepairCostMatch uses a server-side entitlement token to confirm paid Pro access before AI requests are accepted. The RepairCostMatch rate-limit table records only a hashed Pro entitlement identifier and request time; it is not designed to store the AI chat text. The external AI provider may process request content under its own service terms and data controls.

Photos

If you choose a repair photo, the current version creates a temporary local preview for the active browser session. The current RepairCostMatch AI chat does not automatically upload that photo for AI analysis.

Voice description

Voice input, when supported, uses speech-recognition capability provided by your browser. Availability and processing vary by browser and device. Review the transcribed text before continuing.

Project Hub and local storage

If you tap “Save project,” a limited repair snapshot is stored in your browser's local storage on that device. It can include the selected problem, severity, foundation type, ZIP code, planning result and symptom text. It is not currently synced to a RepairCostMatch account or cloud project history.

Quote checker and comparison

Saved quote comparisons are stored in local browser storage in the current version and are not automatically sent to contractors.

No contact information required to start

The basic planning flow does not require your name, email address or phone number.

Provider search

When a verified Pro user searches local companies, the selected ZIP code and repair service are sent to the connected provider-search service to retrieve source-backed local business information. RepairCostMatch does not automatically contact those businesses on your behalf.

Offline and installable web app files

RepairCostMatch may use a service worker and browser cache so public site files load more reliably. This cache is for website assets and is not intended to upload repair-profile data.

Analytics

RepairCostMatch may use analytics to measure page visits and product interactions. Sensitive repair-profile details should not be sent as analytics event parameters.

Security

Private service credentials and AI API keys are kept on server-side systems rather than placed in public website code. Paid AI access is checked server-side and rate limited.

Changes

This notice may change as the service adds or changes AI, contractor matching, analytics, payments or other features.
