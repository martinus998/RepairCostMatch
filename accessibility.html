ACCESSIBILITY

Repair planning should be usable by more people.

RepairCostMatch aims to provide a clear, keyboard-friendly and readable experience across modern phones and browsers. Accessibility is treated as an ongoing product requirement, not a one-time badge.

Our target

We aim toward WCAG 2.2 Level AA practices where practical, including readable contrast, semantic structure, visible focus states, keyboard operation and labels for interactive controls.

Current features

  • Keyboard-accessible buttons and links
  • Skip-to-content links on key informational pages
  • Responsive layouts for small screens
  • Text alternatives or hidden decorative graphics where appropriate
  • Dialogs labeled for assistive technology

Known limits

The site is still evolving and has not been independently certified for accessibility. Some dense visual blueprint elements are decorative and may not convey information to screen-reader users.

Report a problem

If a control cannot be reached, text is hard to read, or an interaction fails with assistive technology, please report the page and the issue. Do not include private homeowner information in a public report.
