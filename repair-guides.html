How to use these guides

Start with the symptom page when you are unsure what repair is needed. Use the cost pages after a contractor or engineer has identified the likely repair category. When comparing bids, check whether each proposal includes the same repair method, quantity, drainage work, engineering, permits, cleanup and restoration.

For a quick planning snapshot based on the problem, severity, foundation type and ZIP code, use the RepairCostMatch repair check. If you already know the repair category and want a budget range first, use the foundation repair cost calculator.

RepairCostMatch provides educational planning information only. Rapid structural movement, unstable walls, flooding, utility damage or other immediate hazards require appropriate local professional evaluation.
